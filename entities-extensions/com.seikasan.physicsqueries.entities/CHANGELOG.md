# Changelog

## 1.0.0 — 2026-10-24

- Unity 6.3 / Entities 1.5.0 / Unity Physics 1.5.0向けに公開APIを確定。
- Raycast、RaycastAll、Collider Cast、Check、Overlapの24拡張メソッドを提供。
- Unity Physics標準のHit型、フィルター、NativeListを利用し、BurstとJob Systemから呼び出せる。
- 方向正規化、無効な有限距離Rayの検証、更新順序、Burst並列Job、GC割り当て、標準APIとの性能比較をテスト。
- RaycastとGround Checkのサンプル、導入・API・制約・検証記録を追加。
