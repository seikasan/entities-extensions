# Changelog

## 1.0.0 — 2026-10-24

- 実接触10,000組で、接触変更率0／10／50／100%・少数／全体受信・複数Consumer・Trigger／Collision併用の48条件を測定。初回・再測定・計測構成の生データ、Native保持量下限、GC、再確保カウンター、テスト結果を保存。一律高速化は確認できず、悪化した観測も記載。
- 容量確保SystemのComponentTypeHandle権限を構成ごとのリテラルで明示し、通常構成で発生したReadOnly権限不一致の安全性エラーを修正。比較対象にも同じ修正を適用。
- Trigger／Collisionの依存鎖を同じ開始依存から分岐し、終了時に結合。計測用NativeReferenceを種類別に分離し、診断時だけ合算。解放・容量変更は対象経路を完了してから行い、例外時もスケジュール済みJobをSystemの依存関係に保持。両経路の破棄と片側の停止／再開の回帰テストを追加。3変更併用時のコンパイル・回帰テスト・性能測定を実行。
- 有効受信者が1体のTrigger／CollisionではEntityを直接比較し、HashMapのClear・登録・検索を省略。対象列挙Jobに準備処理を統合し、準備Jobを1つ削減。切り替え・Disabled・破棄／再生成・再購読の回帰テストを追加。単一／複数受信者を含む実接触の測定を実行。
- 完全一致時は確定済み接触履歴を直接参照し、履歴コピーと毎更新の履歴交換を省略。変化時だけ差分通知の生成後に履歴を更新する方式へ変更。連続Stay・接触消失・再接触の回帰テストを拡張。回帰テストと安定／変動接触での測定を実行。
- PhysicsEventCollectSystemをISystemへ移行。OnUpdateのBurst化は見送り、更新本体・Job準備・スケジュールはManaged、既存JobはBurstで実行。
- 6種類のBuffer、Inspector、購読条件、接触履歴と通知順序、接触列一致時のソート省略を維持。
- 診断メソッドをSystemStateを受け取る形へ移行。テストとベンチマークはSystemHandle経由で更新。
- 計測構成に更新本体のManaged fallback検出とスケジュール区間を追加。通常構成の領域・処理は追加しない。
- 再購読、System／Worldの反復破棄、通知順序、更新本体がManaged・既存JobがBurstで実行される検証を追加。System更新方式ごとの比較結果を性能検証資料に記録。
